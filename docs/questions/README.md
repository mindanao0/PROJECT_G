# วิธีใช้คำถามและคำตอบที่แยกหมวด

เริ่มที่ [ดัชนีหลัก](../02_OPEN_QUESTIONS.md) เลือกหมวดหรือช่วง Q เพื่อเปิดเฉพาะข้อมูลที่ใช้. เลข Q เดิมคงเดิม มีเจ้าของหนึ่งไฟล์ต่อหนึ่งข้อ; ถ้าคร่อมหลายเรื่อง ใช้หมวดหลักและลิงก์อ้าง ไม่คัดคำตอบไปแก้หลายชุด.

- คำตอบทุกครั้งของ Q เดียวอยู่ด้วยกัน อ่านบันทึกล่าสุดและการชี้แจงข้ามข้อก่อนใช้. คำแนะนำ/PROPOSED ไม่กลายเป็นคำยืนยัน. การแยกไฟล์ไม่เปลี่ยนคำตอบ.
- คำตอบแก้ไขเพิ่มในข้อเดิมพร้อมวันที่และประโยคว่าทดแทนส่วนใด ห้ามลบประวัติ. สถานะในบันทึกรุ่นเก่าอาจล้าสมัย.
- Q ใหม่เลือกหมวดจากตารางหลักก่อนบันทึก แล้วเพิ่มใน index ช่วงที่เกี่ยวข้อง. เพิ่มช่วงใหม่ทุก 100 เลข; ไม่ต่อคำตอบทั้งหมดกลับไฟล์ดัชนี.
- ไฟล์หมวดเกินประมาณ 45 ข้อหรือ 14,000 อักขระให้แยกส่วน โดยย้ายทั้งประวัติของ Q เดียวไปด้วยกันและปรับ index/ลิงก์. ขนาดนี้เป็นแนวจัดไฟล์ ไม่ใช่ข้อกำหนดเกม.
- บางคำถามเดิมมีเพียงคำตอบหรือชื่อหัวข้อทั่วไป เก็บตามจริง ไม่สร้างคำถาม/ตัวเลือกที่ขาดขึ้นใหม่แล้วอ้างว่าเป็นต้นฉบับ.
- `history/` เก็บบริบทและตารางเดิมเพื่ออ้างหลักฐาน ไม่เป็นแหล่งคำตอบปัจจุบันแยกอีกชุด. เครื่องหมาย `qa-source` ใช้ยืนยันการย้ายครั้งนี้ รักษาข้อความภายในไว้; คำตอบใหม่เพิ่มนอกบล็อกเดิม.
- คำถามที่ยังถามในแชตและยังไม่มีคำตอบ ไม่ถูกเติมเป็นคำตอบในไฟล์. งานปัจจุบันยังรวบรวมข้อมูล ไม่ร่างประวัติ ผัง หรือภาพ.

ดูผลตรวจการย้ายใน [MIGRATION.md](MIGRATION.md).
