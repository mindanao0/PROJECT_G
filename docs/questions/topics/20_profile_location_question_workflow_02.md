# ขั้นตอนถามประวัติคนและสถานที่ — ส่วน 2

[ดัชนีหมวด](../../02_OPEN_QUESTIONS.md) · [วิธีบันทึก](../README.md)

แต่ละ Q รวมบันทึกเดิมทุกครั้งตามลำดับ อ่านคำตอบล่าสุดของข้อนั้นร่วมกับข้อแก้ไขที่เกี่ยวข้อง อย่าใช้คำแนะนำเก่าเป็นคำตอบยืนยัน. บางข้อเดิมเก็บเฉพาะคำตอบ จึงไม่แต่งตัวเลือกที่ไม่มีในต้นฉบับเพิ่ม.

**ข้อในไฟล์:** [Q550](#q550), [Q598](#q598), [Q622](#q622)

## Q550

**บันทึก 1/1 · บริบทเดิม:** คำตอบบางส่วน Q527–Q550 — 2026-10-16

<!-- qa-source:581 -->
### Q550

**คำตอบเจ้าของ:** A+B+C: เก็บหน้าที่/วิธีเข้าถึง/ผล/จำกัด/ร่องรอย/ชีวิต พร้อมกลไกเชิงเทคนิคและศัพท์สมมติให้สอดคล้องก่อนประวัติ; เก็บแกนก่อนและกลับถามข้อยกเว้นเมื่อจำเป็น ไม่อ้างว่าออกแบบครบแล้วหรือสร้างทฤษฎีจริงแทน.

**สถานะล่าสุด:** ข้อที่เว้น12ข้อได้รับคำตอบตามแนะนำแล้ว ดูบันทึกเพิ่มเติมด้านล่าง.

### Q598

**คำตอบเจ้าของ:** A+B+C: สรุปOPENที่ขวางประวัติร่วมเก็บวัฒนธรรม/ชีวิต/สัมพันธ์และกลุ่มอำนาจ/สถานที่ที่ยังขาดก่อนรายคน. ต้องตรวจซ้ำกับคำตอบเดิม ไม่เริ่มร่างคน/ภาพหรือถามเรื่องตอบแล้ววน.
