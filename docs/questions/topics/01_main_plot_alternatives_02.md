# เสนอแกนเรื่องหลักใหม่ ก่อนกลับไปจัดทีมและประวัติ — ส่วน 2

[ดัชนีหมวด](../../02_OPEN_QUESTIONS.md) · [วิธีบันทึก](../README.md)

## คำสั่งเจ้าของ — 2026-10-21

เจ้าของต้องการเปลี่ยนแกนเรื่องลบความทรงจำ เพราะยังไม่เห็นเดิมพันที่น่าสนใจพอสำหรับการฆ่าปิดปากและการเกี่ยวข้องขององค์กร/รัฐบาล. ให้เสนอเรื่องใหม่ก่อนเลือก ไม่รับคำแนะนำเป็นcanonเอง. P02เปิดทบทวน แกน/4คดี/หลักฐาน/graphเก่าเก็บเป็นประวัติ ยังไม่ถือว่าผ่านสำหรับพล็อตใหม่. ไม่ลบคำตอบเก่าหรือเปลี่ยนกฎเทคโนโลยีแทน. ชุดประวัติQ839–Q862ยังพัก.

## A — โครงการจัดสรรชีวิต

เมืองเสื่อมโทรมกำลังถูกแบ่งว่าเขตไหนจะได้รับน้ำ ไฟ การรักษา การคุ้มครอง และการอพยพเมื่อมีภัยครั้งใหม่. ฝ่ายอำนาจบางกลุ่มปรับข้อมูลและเกณฑ์ให้คนบางย่านถูกตัดออกจากความรับผิดชอบของรัฐ ขณะที่เอกชนได้สิทธิ์พื้นที่และสัญญาฟื้นฟู. คนหายคือผู้ถูกโยกย้าย/กักตัว/ตัดสิทธิ์โดยไม่มีช่องอุทธรณ์ที่ใช้งานได้ และผู้รู้แผนถูกปิดปาก.

เดิมพันคือใครได้อยู่ต่อ ใครถูกปล่อยทิ้ง และทรัพย์/งบฟื้นฟูมหาศาล รัฐเข้ามาเพราะควบคุมการจัดสรรและความมั่นคง; แต่ละฝ่ายอาจอ้างเหตุรักษาเมืองหรือแสวงกำไร ไม่เหมารัฐทั้งหมดเป็นผู้ร้าย. ตัวอย่างเปิดเรื่อง: ทีมช่วยตามหาคนที่ถูกระบุว่าย้ายออกแล้ว แต่พบหลักฐานว่าเขายังอยู่ในเขตที่จะถูกตัดระบบ. งานทีมมีช่วยคน ตรวจเส้นทาง คุ้มครองพยาน และตัดสินใจว่าจะเปิดข้อมูลที่อาจทำให้ตื่นตระหนกเมื่อไร. ใช้โลกเดิมได้มาก; ยังไม่ยืนยันว่ารัฐสร้างวิกฤตเก่า หรือแก้ชะตาพ่อแม่Eliasเอง.

## B — ตลาดซื้อขายความสามารถ (ข้อเสนอแนะนำ)

เทคโนโลยีใหม่ในข้อเสนอนี้ทำให้รูปแบบความชำนาญของมนุษย์กลายเป็นสิ่งที่เก็บ ประเมิน และนำไปใช้งานเชิงพาณิชย์ได้โดยมีข้อจำกัด ไม่ติดตั้งแล้วเก่งทุกอย่างทันที. โครงการเปิดหน้าอ้างช่วยฟื้นฟูทักษะหรือเพิ่มโอกาสทำงาน ขณะที่เครือข่ายลับล่าคนที่มีความสามารถเฉพาะเพื่อเก็บต้นแบบ ส่งให้บริษัทหรือโครงการความมั่นคง. บางคนยอมเข้าร่วมเพราะเงิน บางคนถูกหลอกหรือบังคับ; กระบวนการผิดทำให้สูญเสียความสามารถที่จะใช้ชีวิตหรือทำงาน และบางคนตาย.

เดิมพันคือกำลังคน อำนาจทางทหาร/เศรษฐกิจ สิทธิ์เหนือความสามารถของคน และผลเสียของโครงการที่ฝ่ายหนุนหลังรับผิดไม่ได้. ฝ่ายรัฐบางกลุ่มต้องการข้อได้เปรียบเชิงความมั่นคง บริษัทต้องการผูกขาด องค์กรใต้ดินหาผู้มีทักษะและขายต้นแบบ. การฆ่าปิดปากอาจทำเพื่อเก็บวิธีการ ปิดจำนวนผู้เสียหาย และกันไม่ให้พยานโยงถึงผู้สั่ง ไม่ใช้การลบความจำเป็นแรงหลักของทุกคดี.

ตัวอย่างเปิดเรื่อง: ทีมช่วยคนที่ถูกตามหากลับมาได้ เขาจำครอบครัวและชีวิตเดิมได้ แต่กลับทำสิ่งที่เคยชำนาญไม่ได้. หลักฐานชี้ว่าเขาถูกทดสอบและจัดหมวดมูลค่าความสามารถ. จุดพลิกที่เสนอ: งานตามหาคนที่ทีมเคยรับบางงานอาจมาจากคนที่ต้องการหาตัวผู้มีทักษะไปขาย ทำให้ทีมต้องตรวจผู้ว่าจ้างและผลของงานตนเอง. ทั้งหมดเป็นตัวอย่าง ไม่ยืนยันว่าทีมทำให้ใครถูกจับไปแล้ว.

เข้ากับทีมราว12ที่มีทักษะต่างกันและแนวสมาชิกทำงานต่อไม่ได้: ความสามารถมีความหมายทั้งต่อชีวิตคนและงานทีม. มายาทวงสิทธิ์คนหาย เอเลนาพบผู้รับผลในคลินิก ไอริสค่อยเห็นความต่างระหว่างคำอ้างโครงการกับผลจริง ส่วนอดีตฝ่ายร้ายอาจเคยทำงานให้เครือข่าย; ความเกี่ยวข้องเฉพาะของแต่ละคนยังรอเลือก. Eliasช่วยเชื่อมข้อมูล/อ่านความผิดปกติจากพื้นฐานการรับรู้ โดยยังไม่ใช่ผู้คิดค้นเทคของฝ่ายร้ายหรือทำให้งานทดลองเก่าเป็นต้นกำเนิดคดี.

สิ่งต้องเลือกใหม่ถ้ารับB: เทคทำอะไรได้จริง ใครรับผล ต้นทุน/ข้อจำกัด วิธีพิสูจน์ และสัมพันธ์กับกฎหมาย/เครื่อง/สารเดิมอย่างไร. ไม่ถือว่ากฎเดิมอนุญาตถ่ายทักษะหรือควบคุมคนอยู่แล้ว. บริการย้อนอดีตอาจคงเป็นวัฒนธรรมและเศรษฐกิจของเมือง โดยไม่ต้องทำเป็นทางลับต้นกำเนิดทุกเรื่อง.

## C — สัญญารับฝากชีวิต

ชนชั้นที่มีอำนาจต้องการยืดชีวิตหรือรักษาอิทธิพลด้วยเทคโนโลยีย้าย/สร้างสำเนาตัวตนในร่างคนอื่นตามข้อเสนอใหม่. กิจการเปิดหน้าอ้างรักษาหรือประกันชีวิต ส่วนเครือข่ายลับซื้อหา/กักคนที่เหมาะเป็นร่างรองรับ ผู้รับผลอาจกลับมาหน้าตาเดิมแต่พฤติกรรม ความผูกพัน และการตัดสินใจเปลี่ยน. ตัวอย่างเปิดเรื่อง: ครอบครัวให้ทีมตามหาคนที่กลับมาแล้ว แต่ยืนยันว่าคนที่อยู่บ้านไม่ใช่คนเดิม ขณะที่เอกสารและหลักฐานชีวภาพดูถูกต้อง.

เดิมพันคือสิทธิ์ในร่าง ชีวิต และตัวตน รัฐบางกลุ่มต้องการรักษาคนสำคัญ/ความต่อเนื่องของอำนาจ บริษัทขายการรอดชีวิต และฝ่ายใต้ดินจัดหาร่างหรือช่องทาง. ฆ่าปิดปากเพื่อป้องกันความลับเรื่องผู้ที่สวมชีวิตคนอื่นและที่มาของร่าง. เด่นด้านระทึกขวัญทางจิตวิทยาและความสัมพันธ์ แต่ต้องสร้างกฎตัวตน/ร่าง/สำเนาและข้อจำกัดใหม่มากกว่าA/B. ยังไม่อนุญาตให้สวมร่างหรือลบตัวละครเดิมจริง และไม่ทำให้เส้นรักถูกเปลี่ยนเป็นอีกคนโดยอัตโนมัติ.

## ขอบเขตที่คงระหว่างรอเลือก

Elias/Maya/Elena/Iris/Samir และแนว4เส้นรักยังเป็นฐานการวางคน ไม่ยืนยันว่าแต่ละคนเกี่ยวเทคใหม่แบบไหน. ทีมอิสระและฐานเช่าร่วมคงเป็นกรอบงาน; จำนวนราว12และทักษะ/นักสู้หลัก3คนยังต้องจัดภายในcastเดิม. กติกาเครื่อง/สาร/อุปกรณ์ในตัว การสมัครใจ และหลักฐานเดิมต้องตรวจอีกครั้งหลังเลือกแกนใหม่ ไม่เปลี่ยนโดยนัยจากการเสนอเรื่อง. คำตอบQ898ตีความA+Bเป็นเสี่ยงเหตุร้าย/ทำงานต่อไม่ได้แต่กันการตาย4เส้นรักตามB; ไม่เลือกผู้ตายรายคน. ยังไม่ร่างประวัติ ภาพ หรือบทเต็ม.

## Q901

**สถานะ:** OPEN — เสนอ 2026-10-21 ยังไม่มีคำตอบ

**คำถาม:** อยากใช้แกนเรื่องใหม่ทางไหนเป็นหลัก?

- **A:** โครงการจัดสรรชีวิต — การเอาตัวรอดของเมือง การตัดสิทธิ์ และผลประโยชน์การฟื้นฟู
- **B:** ตลาดซื้อขายความสามารถ — คนถูกล่าเพื่อมูลค่าทักษะ ผูกกับทีมและผลทำงานต่อไม่ได้ (แนะนำ)

- **D:** ขอแนวอื่นหรือผสมบางส่วน โดยระบุสิ่งที่ชอบก่อน ไม่รวมทุกแกนเป็นข้อเท็จจริงเอง
