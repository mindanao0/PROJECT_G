# กลุ่มตัวละคร ชีวิตและชื่อของบทบาทเพื่อนอีกคน — ส่วน 3

[ดัชนีหมวด](../../02_OPEN_QUESTIONS.md) · [วิธีบันทึก](../README.md)

Q815–Q838 เป็นคำถาม OPEN ยังไม่มีคำตอบ. ใช้กับบทบาทเพื่อนอีกคนของ Elias ตามQ791–Q814 ไม่ใช่ประวัติของเอเลนา. บทบาทนี้เป็นชาย30ปี รู้จักมหาวิทยาลัยก่อนวิกฤต ทำงานประสานขนส่ง/ตารางงานทั่วไป. อายุเอเลนายังคง DEFERRED. ข้อเลือกครอบครัว/คู่รักไม่ได้เพิ่มตัวละครมีบทหรือจำนวนcastอัตโนมัติ; ต้องจัดภายในcastรวม30และยังไม่ผูกID. Q834 ไม่ให้รู้เรื่องงานเก่าหรือความสนใจของ Elias ซึ่งยังไม่รู้อะไรตามQ811. Q837–Q838 เป็นข้อเสนอชื่อ/คำสะกดและคำเรียก ไม่ยืนยันสัญชาติหรือเชื้อสาย; Q838ขึ้นกับQ837. Q821 ต้องตรวจช่วงเริ่มเรียน/จบของคนนี้แยก ไม่ใช้timelineของ Elias แทน. ยังรวบรวมคำถาม ไม่ร่างประวัติหรือภาพ และไม่สร้างระบบนัดหมาย/ภารกิจจากตัวเลือก.
