# กลุ่มตัวละคร พื้นเพและเส้นทางงานของเอเลนา — ส่วน 4

**คำชี้แจงก่อนกลับประวัติ — 2026-10-20:** [Q869](02_team_roles_operations_06.md#q869)ระบุเอเลนาเป็นเพื่อนวัยเด็กของEliasแล้ว ส่วนQ850ที่ยังเป็นคำถามเดิมต้องปรับก่อนนำกลับมาถาม ไม่ใช้ตัวเลือกแนะนำช่วงมหาวิทยาลัยแทนคำตอบใหม่. แนวอาจแอบชอบ/ขี้งอน/ปากไม่ตรงใจยังไม่ล็อกเหตุและความรู้สึกลับ; อายุยังDEFERRED. ชุดQ839–Q862ยังไม่มีคำตอบและยังพักไว้ ทำโครงทีมราว12ให้ชัดก่อน.

[ดัชนีหมวด](../../02_OPEN_QUESTIONS.md) · [วิธีบันทึก](../README.md)

**PAUSED ตามลำดับงานเจ้าของ 2026-10-20:** [Q863–Q868](02_team_structure_before_profiles_05.md)รับAครบแล้ว แต่ชุดประวัตินี้ยังไม่มีคำตอบและยังพักไว้ให้จัดบทบาททีม8คน/ลำดับเข้าร่วมก่อน. คำยืนยันQ864ใช้กับงานคลินิกทั่วไปแยกศูนย์สถาบันเฉพาะส่วนที่ครอบคลุม ไม่ใช่การรับคำแนะนำทั้งQ839–Q862. ก่อนกลับมาถามให้ตัดคำถามส่วนที่โครงตอบแล้ว ไม่ถามยืนยันเรื่องเดิมซ้ำ.

Q839–Q862 ยังไม่มีคำตอบ ใช้กับC01เอเลนา. อายุยัง DEFERREDตามQ793ล่าสุด ไม่กลับไปล็อก29หรือ30. เป็นการเก็บข้อมูลก่อนร่างประวัติ ไม่ใช่ประวัติหรือภาพ. Q839/Q848เป็นข้อเสนอหน้าที่และเส้นทางฝึกในโลกเกม ไม่ใช่ข้อกำหนดวิชาชีพจริง; เลือกหน้าที่ให้สอดคล้องก่อนใช้. Q840–Q842ไม่เปลี่ยนว่าบริการความทรงจำทั้งหมดผิดกฎหมาย และศูนย์สถาบันเข้าถึงเฉพาะเจ้าหน้าที่ตามกฎเดิม ไม่เปิดศูนย์ประชาชนจากคำว่าclinic. ความเชื่อของเอเลนาไม่ยืนยันความจริง/ความชอบธรรมของกิจการ. Q850/Q853ไม่บังคับอายุเท่าEliasหรือให้ความรู้จากการเรียน/เพื่อนอัตโนมัติ. Q852ต้องคงว่าเธอไม่รู้ผลทดลองตามQ213; งานเก่าEliasไม่เกี่ยวกำเนิดคดี. Q861ไม่เปิดเส้นรักหรือบังคับอดีตรักจริงจัง. ไม่มีข้อมูลผู้รับบริการส่งต่อเพียงเพราะสัมพันธ์ดี และไม่เพิ่มcastจากครอบครัวอัตโนมัติ.
