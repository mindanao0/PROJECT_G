## Q1022

**คำถาม:** ตาราง 9 หมุดเหตุที่เสนอ ใช้เป็นโครงทำงานต่อได้ไหม?

- **A:** ใช้ลำดับโดยรวมก่อน แล้วปรับรายละเอียดระหว่างออกแบบ โดยยังไม่ล็อกจำนวนคดีหรือบท
- **B:** ใช้ได้ แต่ต้องปรับจังหวะสมาชิกเข้าทีมก่อน
- **C:** พักตารางไว้ก่อน กลับไปจัดบทบาททีมให้ครบ

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** B พร้อมคำแก้ไขจังหวะก่อนจบครึ่งแรก — เจ้าของระบุโดยตรง

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

คำตอบเจ้าของ: “รู้สึกเหมือนฝั่งตัวร้ายจะเข้าทีมกับอดีตตัวร้ายดูจะช้าไปหน่อยมันน่าจะควรรวมทีมเเละเคลียปัญหาเบื่องหลังให้จบก่อนจบครึ่งเเรกเเละอาจจะเปิดตัวคนที่หักหลังไปด้วยเลย”. ปรับIris/หญิงอดีตฝ่ายร้ายและการรวมทีมหลักให้เร็วขึ้น เปิดและคลี่คลายปมเบื้องหลังที่ขวางการร่วมทีมก่อนจบครึ่งแรก ไม่ลากปมเข้าทีมเป็นแกนถึงครึ่งหลัง. “อาจ”เปิดคนหักหลังเป็นPROPOSED ตัวตน/บทบาทยังOPEN ไม่สร้างคนทรยศในทีมเอง. ผลความผิด/ผู้เสียหายตามQ1017/Q1040ยังอยู่; ไม่รับตารางเดิมทั้งชุดหรือบังคับครบ12ทุกroute

## Q1023

**คำถาม:** หลักฐานอะไรควรเป็นตัวเชื่อมว่าโครงการเป็นของรัฐจริง?

- **A:** คำอนุมัติและการจัดสรรทรัพยากรที่ตรวจสอบได้ว่ามาจากผู้มีอำนาจ
- **B:** ข้อมูลภายในสถานทดลองที่ตรงกับการขนส่ง บุคลากร และคำสั่งภายนอก
- **C:** ต้องใช้ทั้ง A+B ประกอบกัน ไม่มีหลักฐานชิ้นเดียวเฉลยทุกอย่าง

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ ต้องตรวจหลายแหล่ง ไม่ทำข้อความเดียวเฉลยทุกอย่าง

## Q1024

**คำถาม:** ทีมควรได้ข้อมูลสำคัญชุดนี้มาอย่างไร?

- **A:** ภารกิจช่วยคนทำให้เข้าถึงข้อมูลของสถานทดลองย่อย แล้วตามเชื่อมกับแหล่งอื่น
- **B:** เจ้าหน้าที่วงในนำมาให้ แต่ทีมต้องตรวจสอบและปกป้องเขา
- **C:** บริษัทคู่สัญญาพยายามใช้ข้อมูลแลกความปลอดภัยของตัวเอง

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ ยังไม่เลือกสถานย่อย/ชิ้นข้อมูลจริง

## Q1025

**คำถาม:** ทำไมข้อมูลที่พบจึงยังไม่พอเปิดโปงต่อสาธารณะทันที?

- **A:** พิสูจน์ได้ว่ามีโครงการ แต่ยังระบุผู้สั่งและผู้รับผิดชอบได้ไม่ครบ
- **B:** การเปิดข้อมูลจะเผยตัวพยานหรือคนที่ยังติดอยู่ในโครงการ
- **C:** มีทั้ง A+B ทีมจึงต้องเลือกว่าเปิดอะไร เมื่อไร และช่วยใครก่อน

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ แยกพิสูจน์เจ้าของโครงการได้จากระบุทุกคน/พร้อมเผยแพร่โดยไม่กระทบพยาน

## Q1026

**คำถาม:** ไอริสควรช่วยยืนยันหลักฐานด้วยอะไรหลังลาออก?

- **A:** ความรู้เรื่องขั้นตอน รูปแบบคำสั่ง และความผิดปกติของสายรายงาน โดยต้องมีข้อมูลภายนอกตรวจประกอบ
- **B:** คนรู้จักในหน่วยงานที่ยังยอมช่วยอย่างจำกัด
- **C:** ข้อมูลบางส่วนที่เธอเก็บไว้ก่อนลาออก ซึ่งทำให้ถูกตามตัว

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ ความรู้ไม่เท่ากับยังมีสิทธิ์ระบบ ไม่สร้างหลักฐานที่มีเพียงIrisคนเดียวเข้าถึงได้จนล็อกทางสืบ

## Q1027

**คำถาม:** ผลจากการรายงานของไอริสที่ทำให้พยานตกอยู่ในอันตราย ควรหนักแค่ไหน?

- **A:** พยานถูกจับกลับไป ทีมมีโอกาสช่วยภายหลัง
- **B:** พยานเสียชีวิต ทำให้เธอต้องรับผลที่แก้คืนไม่ได้
- **C:** พยานหนีรอดแต่สูญเสียบ้าน งาน หรือความปลอดภัย และไม่ไว้ใจเธออีก

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** B — เจ้าของระบุโดยตรง

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

เจ้าของเลือกB พยานเสียชีวิตจากผลของการรายงาน ไม่ใช้เส้นช่วยรอด/ช่วยภายหลังแทน. ยังไม่เลือกชื่อ ตัวตน วิธีหรือผู้ลงมือ; ไม่ผูกเป็นสมาชิกต้นแบบหรือสี่เส้นรักโดยนัย และไม่ใช่ผู้ทดลองคนแรกที่สื่อสารไม่ได้

## Q1028

**คำถาม:** ไอริสควรบอกทีมเรื่องความผิดพลาดของตัวเองเมื่อไร?

- **A:** บอกเองเมื่อพบว่าข้อมูลจากเธอถูกใช้ตามเก็บพยาน แม้เสี่ยงเสียความไว้ใจ
- **B:** พยายามแก้ก่อน แล้วจึงบอกเมื่อพบว่ารับมือคนเดียวไม่ได้
- **C:** ทีมค้นพบก่อน ทำให้การเลือกข้างของเธอต้องผ่านความขัดแย้งหนักขึ้น

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ แยกเวลารู้การรั่วกับรู้การเสียชีวิตตามหลักฐาน ไม่ให้รู้เหตุทั้งหมดทันทีโดยไม่มีที่มา

## Q1029

**คำถาม:** หลังลาออก รัฐควรใช้เหตุอะไรติดตามไอริส?

- **A:** กล่าวหาว่านำข้อมูลจำกัดสิทธิ์ออกไปและขัดขวางการปฏิบัติงาน พร้อมบิดเบือนสิ่งที่เธอทำ
- **B:** ยังไม่กล่าวหาอย่างเป็นทางการ แต่ส่งคนเฝ้าติดตามและกดดันคนรอบตัว
- **C:** ประกาศว่าเธอร่วมมือกับกลุ่มอาชญากรรม ทำให้ทีมถูกมองเป็นภัยไปด้วย

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A+B — เจ้าของระบุโดยตรง

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

เจ้าของเลือกA+B มีการเฝ้าติดตาม/กดดันในจังหวะที่ยังไม่กล่าวหาอย่างเป็นทางการ และใช้ข้อกล่าวหานำข้อมูล/ขัดขวางที่บิดเบือน. ช่วงBก่อนขั้นกล่าวหาAใช้เป็นข้อเสนอเรียงเหตุ ไม่ทำพร้อมกันว่าแจ้งข้อหาแล้วแต่ยังไม่แจ้ง; เวลา/ข้อกล่าวหาเฉพาะยังต้องเลือก

## Q1030

**คำถาม:** คำสั่งสำคัญที่หัวหน้าหน่วยหญิงขัดควรเป็นอะไร?

- **A:** ให้กำจัดพยานและคนในพื้นที่ที่ไม่เกี่ยวข้อง เพื่อไม่ให้รัฐตามรอยถึงองค์กร
- **B:** ให้ส่งผู้ทดลองที่เธอรับปากว่าจะปล่อยกลับไปทดลองต่อ
- **C:** ให้ทิ้งหน่วยของตัวเองเป็นตัวล่อ ทั้งที่เธอพบว่าผู้นำกำลังปิดปากคนในงานนั้นด้วย

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** C — อ่านร่วมQ1032/Q1034 — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ แต่Q1032=Cเธอรู้การกำจัดชัดเมื่อหน่วยถูกลงมือ และQ1034=Cเธอหนีโดยไม่ช่วยลูกน้อง. ไม่เขียนความขัดคำสั่งเป็นวีรกรรมปกป้องลูกน้องจนสุด. จังหวะสงสัยคำสั่ง/ขัดคำสั่ง/ยืนยันการเก็บยังต้องเรียง ไม่สร้างหลักฐานล่วงหน้าแทนC

## Q1031

**คำถาม:** ความผิดพลาดที่ผู้นำต้องการปิดด้วยการกำจัดทั้งหน่วยคืออะไร?

- **A:** งานชิงเทคทำให้ข้อมูลการค้าลับระหว่างผู้นำองค์กรกับคนในรัฐรั่ว
- **B:** หน่วยพบว่าโครงการขององค์กรใช้ข้อมูลทดลองที่ปกปิดความเสี่ยงจากคนของตัวเอง
- **C:** งานล้มเหลวจนรัฐตามรอยใกล้ถึงผู้นำ เขาจึงโยนความผิดให้หน่วยแล้วตัดทิ้ง

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ ชื่อภารกิจ/สิ่งที่ล้มเหลวและผู้สั่งเฉพาะยังต้องวาง ไม่ยืนยันความตายทั้งหน่วย

## Q1032

**คำถาม:** เธอรู้คำสั่งกำจัดหน่วยได้อย่างไร?

- **A:** พบความผิดปกติของคำสั่งและการจัดกำลัง แล้วได้หลักฐานยืนยันภายหลัง
- **B:** คนในองค์กรเตือนเพื่อแลกผลประโยชน์
- **C:** หน่วยถูกลงมือก่อน เธอจึงรู้ว่าต้นสังกัดกำลังฆ่าคนของตัวเอง

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** C — เจ้าของระบุโดยตรง

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

เจ้าของเลือกC หน่วยถูกลงมือแล้วเธอจึงรู้ชัดว่าองค์กรกำลังเก็บคน ไม่ให้คนเตือนหรือข้อมูลก่อนเหตุเป็นตัวเฉลยแทน. ยังไม่กำหนดว่าใครเสียชีวิต/รอด

## Q1033

**คำถาม:** ทำไมลูกน้องยังมองเธอเป็นคนทรยศ แม้มีคำสั่งกำจัดหน่วย?

- **A:** พวกเขาไม่รู้คำสั่งจริง ได้รับข้อมูลว่าเธอขายหน่วยให้ศัตรู
- **B:** รู้ว่ามีคำสั่ง แต่เชื่อว่าเป็นผลจากการขัดคำสั่งของเธอ
- **C:** รู้บางส่วน แต่เชื่อว่าถ้าจับหรือกำจัดเธอได้ องค์กรจะยอมรับพวกเขากลับ

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ ผู้ที่ยังอยู่รับข้อมูลว่าเธอขายหน่วย ไม่ทราบคำสั่งจริง. การถูกโจมตีไม่ทำให้ทุกคนรู้ว่าใครสั่งอย่างเดียวกัน ต้องแยกหลักฐานที่เธอเห็นกับสิ่งที่ลูกน้องได้รับ. Q954ทุกคนภักดีองค์กรยังเดิม

## Q1034

**คำถาม:** เธอควรพยายามช่วยลูกน้องก่อนออกจากองค์กรไหม?

- **A:** พยายามเตือนหรือเปิดทางให้ แต่ลูกน้องไม่เชื่อและยังทำตามองค์กร
- **B:** พยายามเฉพาะบางคนที่ยังเข้าถึงได้ ก่อนต้องเลือกเอาตัวรอด
- **C:** เธอเลือกหนีโดยไม่ช่วย ทำให้ความรับผิดชอบส่วนนี้ตามมาหลังเข้าทีม

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** C — เจ้าของระบุโดยตรง

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

เจ้าของเลือกC เลือกหนีโดยไม่ช่วย ไม่เพิ่มฉากพยายามช่วยสำเร็จหรือเตือนอย่างเสียสละเพื่อล้างความผิด. ทีมและผู้เสียหายมีเหตุไม่ไว้ใจเธอ ส่วนการเข้าทีมก่อนครึ่งแรกไม่ลบผลการตัดสินใจนี้

## Q1035

**คำถาม:** ตอนเธอหันมาหาทีมตัวเอก เธอต้องการอะไรเป็นอันดับแรก?
