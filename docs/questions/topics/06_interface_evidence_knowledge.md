**คำตอบล่าสุดเจ้าของ:** Q16 CONFIRMED 2026-10-14: ใช้แนว A แต่ไม่แสดงค่าความสัมพันธ์หรือค่าตัวแปรที่กำหนดผลเนื้อเรื่อง. แสดงเฉพาะข้อมูลทั่วไปที่จำเป็นต่อ gameplay เช่นทักษะ Level ความพร้อม/ข้อจำกัดภารกิจ. ท่าทีและความสัมพันธ์รับรู้ผ่านบทพูดและการกระทำ ไม่ใช้หน้าจอเปิดค่าลับหรือ threshold; รายการ UI gameplay ที่แน่นอนยังรอออกแบบ.

**คำตอบล่าสุดเจ้าของ 2026-10-14 (ใช้แทนข้อเสนอ/คำตอบก่อนหน้าที่ขัดกัน):** ยังไม่เข้าใจรูปแบบแสดงสถานะ ขอคำอธิบายพร้อมตัวอย่างก่อนเลือก; ยัง OPEN.

**แนะนำ A:** แสดงท่าที/ข้อผูกมัดเป็นภาษา และแสดง Level/หลักฐานชัดเจน; ตัวเลข relation ใช้ debug เท่านั้น

**B:** แสดงเลข relation ทั้งหมด · **C:** ซ่อนเกือบทั้งหมด — ต้องทดสอบว่าผู้เล่นยังเข้าใจเหตุและผล

**ผล/ระหว่างรอ:** D10, P06/P08; ไม่มีแถบ “คนดี/คนเลว” รวมทุกความสัมพันธ์เป็นค่าเดียว
