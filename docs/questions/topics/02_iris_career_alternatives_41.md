# Iris — ทบทวนอาชีพ Q1767

## Q1767

เจ้าของขอเปลี่ยนอาชีพ ให้เข้ากับโลก cyberpunk เกี่ยวกับเทคโนโลยีหรือ hacker; งานเดิมของ Iris ต้องไม่เกี่ยวโครงการลับ. ทีมมีช่างอุปกรณ์และผู้เชี่ยวชาญดิจิทัลอยู่แล้ว. ข้อเสนอชุดก่อนที่โยงโครงการลับ/ความทรงจำถูกถอน.

- A. แฮกเกอร์สอดแนม/ปลอมตัวดิจิทัล: สร้างตัวตนชั่วคราว ปลอมสิทธิ์หรือแฝงระบบ ต้องเตรียมข้อมูลและช่องทาง; ตัวอย่างเหตุพบทีมคือจ้างช่วยเข้าถึงข้อมูล/สถานที่. (แนะนำ)
- B. เทคภาพลวงตา/ปลอมภาพ: ภาพฉาย/พราง/ตรวจภาพขึ้นกับอุปกรณ์.
- C. แฮกเกอร์อุปกรณ์เชื่อมร่างกาย: วิเคราะห์ซอฟต์แวร์และการสื่อสาร ช่างดูชิ้นส่วนกายภาพ; ตัวอย่างพบทีมผ่านอุปกรณ์ในคดี.
- D. ผู้เชี่ยวชาญระบบเมืองอัตโนมัติ: กล้อง ประตู ขนส่ง วางแผนผ่านพื้นที่.
- E. แฮกเกอร์ข่าวกรองดิจิทัล: ติดตามร่องรอยบุคคล/องค์กร ตรวจแหล่งข้อมูล; ตัวอย่างพบทีมจากคนหาย.
- F. ผสม; G. ขอแนวอื่น.

เหตุพบทีม งานเดิม สิทธิ์และวิธีเข้าถึงแต่ละอย่างเป็นตัวอย่าง ไม่ใช่คำตอบอัตโนมัติ. [คำตอบ](../../answers/02_iris_career_q1767.md)
