# โครงบทบาท ทีม และฐาน ก่อนกลับไปถามประวัติ — ส่วน 5

[ดัชนีหมวด](../../02_OPEN_QUESTIONS.md) · [วิธีบันทึก](../README.md)

## คำสั่งเจ้าของล่าสุด — 2026-10-20

เจ้าของให้ทำโครงก่อนประวัติ: ต้องรู้ว่าเอเลนาเป็นใคร/ตัวหลักและเส้นรักได้ไหม ทำงานสำนักงานใหญ่หรือไม่ ใครมาชวน ทีมทำกันเองหรือมีองค์กรรัฐ/ตำรวจจัดหา จำนวนสมาชิก และฐานมาจากไหน. พัก Q839–Q862 ไว้ก่อน ไม่ต้องตอบหรือรับคำแนะนำชุดนั้นตอนนี้. ลำดับใหม่คือโครงบทบาท/องค์กร/ทีม/ฐาน → ทวนกฎและความรู้เดิม → คำถามประวัติรายคน → ร่างเมื่อได้รับคำสั่ง → รูปลักษณ์/ภาพภายหลัง.

## โครงที่รับใน Q863–Q868 — จำนวนและเส้นรักมีคำแก้ไข Q869 ภายหลัง

**ปัจจุบัน:** จำนวน8ถูกปรับเป็นกรอบราว12ตาม [Q869](02_team_roles_operations_06.md#q869) และรายชื่อเส้นรักเป็น4คนแล้ว. สำนักงานอิสระ มายาผู้ชวน คลินิกทั่วไปและวิธีเช่าฐานยังเดิม. ย่อหน้าถัดไปเป็นคำตอบรอบก่อนแก้.

เจ้าของตอบ “เอาตามเเนะนำ” รับQ863–Q868=Aครบ6ข้อ. เอเลนาเป็นตัวหลักและหนึ่งในตัวเลือกความรัก งานดูแลสุขภาพในคลินิกทั่วไปแยกจากศูนย์สถาบัน; มายายังคงเป็นผู้ชวนเพิ่งพบ. ทีมเริ่มร่วมสืบกันเองแล้วค่อยเป็นสำนักงานสืบ/ช่วยตรวจข้อมูลอิสระที่มีงานสุจริตรองรับ ทีมเต็ม8รวมElias ทยอยเพิ่ม; สมาชิกตกลงเช่าฐานเล็กจากรายรับงานและเงินร่วมเมื่อทีมเป็นรูปเป็นร่าง. ไม่ใช่ทีมที่ตำรวจจัดตั้งหรือจัดฐานให้จากคำตอบนี้ ไม่มีอำนาจตำรวจอัตโนมัติ.

การจัดบทบาทและลำดับเข้าร่วมของทั้ง8ยังต้องวางก่อนกลับประวัติ. ชื่อสำนักงาน ผู้จัดหา/ผู้รับผิดชอบสัญญาฐาน ขนาดงบ และอำนาจตามกติกาโลกเกมยังไม่กำหนด. รายชื่อเส้นรักรวมไม่ยืนยันครบเพราะรับเอเลนาเฉพาะQ863. Q839–Q862ยังไม่มีคำตอบและยังพักไว้; ไม่รับคำแนะนำประวัติทั้งชุดจากการรับโครง. ตารางด้านล่างเป็นสถานะก่อนคำตอบเพื่ออ้างประวัติ; ใช้คำตอบล่าสุดรายข้อเป็นหลัก.

## ภาพรวมที่เสนอรอบก่อนตอบ — เก็บเป็นประวัติ ขอบเขตยืนยันดูคำตอบล่าสุด

เอเลนาเป็นตัวหลัก/เส้นรักที่มีชีวิตและหน้าที่ของตน งานคลินิกสุขภาพทั่วไปแยกจากสำนักงานใหญ่สถาบัน; ไอริสคงบทคนฝั่งสถาบัน ส่วนมายาเป็นคนมาชวนElias. การร่วมสืบเริ่มจากคนไม่กี่คนที่มีเหตุเกี่ยวข้อง แล้วค่อยมีสำนักงานอิสระเล็กสำหรับงานสืบ/ตรวจข้อมูลตามกติกาโลกเกม ไม่มีอำนาจจับกุม ค้น หรือสิทธิ์ฐานข้อมูลตำรวจอัตโนมัติ. เสนอทีมเต็ม8รวมEliasโดยทยอยเพิ่ม มีบทวิเคราะห์ ประสาน สืบข้อมูล ภาคสนาม คุ้มกัน เทคนิค และดูแลคน; หนึ่งคนมีบทบาทรองได้ ไม่ผูกผู้ยังไม่กำหนดเข้าชื่อเดิม. ยังไม่กำหนดทั้ง8คนหรือสถานะสมาชิกไอริสจากการถูกส่งติดตาม. Eliasอาจค่อยรับบทวิเคราะห์/จัดคนโดยฟังข้อมูลเพื่อน ไม่อ้างว่าประสบการณ์นำทีมมีแล้ว. ฐานเสนอเช่าตามกำลังจากรายรับงาน/เงินร่วม ต้องเลือกผู้รับผิดชอบและสเกลเงินหลังโครงผ่าน ไม่รับข้อเสนอสกุลเงินเดิมอัตโนมัติ.

การเลือกทางการ/สำนักงานใหญ่หรือเปลี่ยนผู้ชวนทำได้เมื่อเจ้าของยืนยัน แต่ต้องทวนกฎการเข้าถึง คนเพิ่งพบ เหตุเข้าร่วม และknowledge ไม่เปลี่ยนหลักเก่าเงียบ. งานบุคคลยังไม่ร่างและยังไม่สร้างองค์กร/พื้นที่เป็นข้อเท็จจริงจากข้อเสนอ.

**คำถาม:** ตำแหน่งงานของเอเลนาควรอยู่ฝั่งไหนก่อนเลือกวิชาชีพละเอียด?

## Q866

**สถานะ:** CONFIRMED — รับคำตอบ 2026-10-20

**คำตอบเจ้าของ:** A — เริ่มจากร่วมสืบกันเอง แล้วค่อยจัดเป็นสำนักงานสืบ/ช่วยตรวจข้อมูลอิสระที่ทำงานภายใต้กติกาโลกเกม มีงานสุจริตรองรับ ไม่มีอำนาจตำรวจอัตโนมัติ.

**ที่มาคำตอบ:** เจ้าของรับตามคำแนะนำครบQ863–Q868.

**ขอบเขต:** โครงองค์กรยืนยันแล้ว แต่ชื่อสำนักงาน ผู้รับผิดชอบ การเริ่มจด/จัดตั้ง และงานรับจริงยังต้องวางในกติกาโลกเกม.

**คำถาม:** รูปแบบองค์กรของทีมควรเป็นแบบไหน?

- **A:** เริ่มจากร่วมสืบกันเอง แล้วค่อยจัดเป็นสำนักงานสืบ/ช่วยตรวจข้อมูลอิสระที่ทำงานภายใต้กติกาโลกเกม มีงานสุจริตรองรับ ไม่มีอำนาจตำรวจอัตโนมัติ (แนะนำ)
- **B:** ทีมทางการที่หน่วยงานรัฐหรือองค์กรตำรวจจัดตั้ง จัดคนและสถานที่ให้ ต้องทวนว่าเหตุใดยอมช่วยคดีนี้ในเมืองที่ประชาชนถูกละเลย
- **C:** ทีมอิสระที่ร่วมงานกับหน่วยงานทางการบางส่วนเป็นรายกรณี ต้องกำหนดทุน อำนาจ และข้อมูลที่แต่ละฝ่ายควบคุม

**คำถาม:** ฐานประสานของทีมควรได้มาอย่างไร เมื่อทีมเริ่มเป็นรูปเป็นร่าง?

- **A:** สมาชิกตกลงเช่าพื้นที่เล็ก ใช้รายรับงานและเงินร่วมตามกำลัง ต้องกำหนดผู้รับผิดชอบจริงก่อนใช้ (แนะนำ)
- **B:** คนที่มีสิทธิ์ในพื้นที่ให้ใช้ตามข้อตกลง ต้องเลือกผู้ให้และเงื่อนไขภายหลัง
- **C:** องค์กรทางการจัดให้ เหมาะเมื่อเลือกรูปแบบทีมที่มีการสนับสนุนทางการ และต้องกำหนดข้อผูกมัด
