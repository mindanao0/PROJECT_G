### Q14 — ย้อนตัวเลือกและกลับมาเล่นใหม่ได้แค่ไหน?

**คำตอบล่าสุดเจ้าของ 2026-10-14 (ใช้แทนข้อเสนอ/คำตอบก่อนหน้าที่ขัดกัน):** A: หลายช่องเซฟ โหลด rollback และ skip เฉพาะอ่านแล้ว; journal ย้อนตาม save.

### Q15 — ความกดดันด้านเวลาเป็นแบบไหน?

**คำตอบล่าสุดเจ้าของ 2026-10-14 (ใช้แทนข้อเสนอ/คำตอบก่อนหน้าที่ขัดกัน):** จับเวลาเฉพาะคำถามที่ต้องตัดสินใจด่วน/เหตุการณ์เฉพาะหน้า; คำถามอื่นไม่จับเวลา ไม่แยกด้วยว่ามีผลเนื้อเรื่องหรือเป็นบทสนทนาทั่วไป. เวลาภายในเรื่อง/การส่งทีม ระยะเวลานับถอยหลัง ผลหมดเวลา และตัวเลือกปิด timer ยังเปิด.

**แนะนำ A:** เวลาผ่านเมื่อเลือกการกระทำสำคัญ ไม่ใช่เวลาที่ใช้อ่าน · **B:** ตัวเลือกจับเวลาที่ปิดได้ · **C:** มีเวลาจริงเป็น core mechanic — ต้องแก้ accessibility และ QA

**ผล/ระหว่างรอ:** D10, P05/P08; S0 ใช้ A, ไม่มีนับวินาทีหรือ randomized deadline
