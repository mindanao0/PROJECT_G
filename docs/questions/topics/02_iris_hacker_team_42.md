# Iris — รวมบทบาทดิจิทัลและผลต่อเรื่อง Q1768–Q1773

## Q1768
สัมพันธ์กับผู้เชี่ยวชาญดิจิทัลเดิม: A Iris เป็นคนนั้น รวมบทบาทและปรับหน้าที่ตาม A+C+E (แนะนำ); B สองคนแบ่งความถนัด; C ร่วมบางครั้งไม่เป็นสมาชิกหลัก; D เปรียบเทียบบทบาทก่อน; E อื่น.
## Q1769
ด้านเด่นที่สุด: A แฝงตัว/สร้างตัวตนดิจิทัลเข้าระบบ (แนะนำ); B ซอฟต์แวร์อุปกรณ์เชื่อมร่างกาย; C ข่าวกรอง/ร่องรอยดิจิทัล; D เด่นใกล้เคียงกัน; E ไม่เลือก.
## Q1770
แบ่งงานช่าง: A Iris ดูซอฟต์แวร์/ข้อมูล ช่างตรวจซ่อมปรับชิ้นส่วนกายภาพ ทำงานร่วมเมื่อมีทั้งสอง (แนะนำ); B แทนกันได้ทั้งหมด; C Iris ดูอุปกรณ์ร่างกายทุกส่วน; D ไม่เลือก.
## Q1771
งานก่อนพบทีม: A รับงานอิสระเจาะระบบและค้นข้อมูลเลือกงานเอง (แนะนำ); B ทดสอบความปลอดภัยบริษัททั่วไป; C หน่วยรัฐไม่เกี่ยวโครงการลับ; D ไม่เลือก; E อื่น.
## Q1772
พบทีม: A Maya จ้างช่วยงานดิจิทัล (แนะนำ); B ตามคนเดียวกันและพบระหว่างงาน; C คนรู้จักแนะนำให้พบ Elias; D ไม่เลือก. ผู้ใช้แก้ A ว่า **Elias เป็นคนติดต่อ**.
## Q1773
จัดการเหตุเดิม: A ทบทวนแต่ละเหตุการอยู่คดีแรก ลาออก รายงานพยาน เข้าทีม แล้วเสนอเก็บ/ปรับ/ถามใหม่ (แนะนำ); B ลบทั้งหมด; C เก็บทั้งหมดไม่ปรับ; D พัก.
