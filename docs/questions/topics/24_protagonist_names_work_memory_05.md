# ตัวเอก ชื่อ งาน และความเกี่ยวข้องส่วนตัวกับความทรงจำ — ส่วน 5

[ดัชนีหมวด](../../02_OPEN_QUESTIONS.md) · [วิธีบันทึก](../README.md)

Q767–Q790 เป็นคำถาม OPEN ยังไม่มีคำตอบ. ชื่อและคำสะกดไทยเป็นข้อเสนอสร้างสรรค์สำหรับเลือก ไม่ยืนยันสัญชาติหรือเชื้อสายจากชื่อ. Q767/Q768 เลือกแยกหรือเสนอคู่ใหม่ได้; Q769 ขึ้นกับชื่อจริง. Q772 เป็นกรอบอายุโดยประมาณจากคำตอบก่อนหน้า ไม่ล็อกวันเดือนปี. Q773 แยกลูกค้าบริการจากการทดลองเก่า ไม่ตัดสินว่าใครเป็นผู้ทดลอง. Q775–Q776 ไม่แทนตัวเลือกผู้เล่น และไม่เปลี่ยน Q724 ที่ประเมินแต่ไม่ได้ช่วย. ของทดลองเก่าไม่อนุมานว่าเป็นเครื่องบริการหลักหรือว่าถูก/ผิดกฎหมายจนรู้หน้าที่และช่วงเวลา. ไม่เปลี่ยนเหตุเลิกทดลอง ไม่เชื่อมกำเนิดคดี และยังไม่ร่างประวัติหรือภาพ.
