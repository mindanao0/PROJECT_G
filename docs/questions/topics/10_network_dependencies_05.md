# เครือข่ายจัดหา คนกลาง บริษัท และอำนาจ — ส่วน 5

[ดัชนีหมวด](../../02_OPEN_QUESTIONS.md) · [วิธีบันทึก](../README.md)

รับคำตอบ2026-10-22. ข้อที่ไม่ได้ระบุใช้คำแนะนำตามคำสั่งเจ้าของ. เป็นหลักการของเครือข่ายก่อนประวัติและคดีเต็ม ไม่สร้างเหตุการณ์เฉพาะหรือผังสถานที่ยืนยันเอง. Q973/Q975มีคำแก้ไขตรงจากเจ้าของ ใช้เหนือคำแนะนำเดิม.

## Q962

**คำถาม:** เครือข่ายจัดหาคนให้โครงการรัฐควรเริ่มจากไหน?

- **A:** ช่องทางเปิดหน้า เช่น รับสมัครงานหรือโครงการรักษา ก่อนหลอกพาคนเข้าไป
- **B:** เครือข่ายใต้ดินที่ลักพาตัว ซื้อขายคน หรือบีบบังคับลูกหนี้
- **C:** มีทั้ง A+B แต่คนที่ถูกเลือกต้องมีคุณสมบัติตรงกับสิ่งที่โครงการต้องการ

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ ไม่เลือกกิจการ/เหยื่อรายคนเอง

## Q963

**คำถาม:** องค์กรอาชญากรรมเคยรับผิดชอบส่วนใดให้รัฐมากที่สุด?

- **A:** จัดหาคน ขนส่ง และกำจัดร่องรอย โดยเข้าไม่ถึงฐานหลัก
- **B:** คุมสถานทดลองย่อยบางแห่งให้รัฐด้วย
- **C:** จัดหาผู้เชี่ยวชาญและวัสดุผิดกฎหมายเป็นหลัก ไม่เคยส่งคนทดลองโดยตรง

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

## Q964

**คำถาม:** หลังแตกหัก เครือข่ายเดิมยังใช้งานร่วมกันแค่ไหน?

- **B:** ยังแย่งใช้คนกลาง เส้นขนส่ง และสถานที่เดิม ทำให้ทีมพบร่องรอยซ้อนกัน
- **C:** องค์กรยึดเครือข่ายส่วนใหญ่ไป รัฐต้องสร้างช่องทางใหม่

**แนะนำเดิม:** B

## Q965

**คำถาม:** คนกลางที่เชื่อมรัฐกับองค์กรมีลักษณะอย่างไร?

- **C:** มีผู้ประสานงานจากบริษัทคู่สัญญาคอยควบคุมคนกลางทั้งหมด

## Q966

**คำถาม:** ทีมควรค้นพบเครือข่ายจากข้อมูลแบบไหน?

## Q969

**คำถาม:** ถ้าทีมช่วยคนออกจากช่องทางจัดหาได้ ผลต่อโครงการควรเป็นอย่างไร?

- **A:** โครงการเสียต้นแบบสำคัญ จึงต้องเลื่อนหรือเปลี่ยนแผนทดลอง
- **B:** โครงการหาคนทดแทนจากช่องทางอื่น แต่ทีมได้พยานและคนที่ช่วยไว้ยังปลอดภัยขึ้น
- **C:** ต่างกันตามความสำคัญของคนที่ช่วย มีทั้ง A+B

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

## Q970

**คำถาม:** ภารกิจเกี่ยวกับขนส่งควรมีเดิมพันอะไรเป็นหลัก?

- **A:** ต้องระบุให้ได้ว่าขบวนไหนขนคน ขบวนไหนขนอุปกรณ์ ก่อนตัดสินใจ
- **B:** ต้องเลือกระหว่างช่วยผู้ถูกส่งตัวกับตามรอยไปยังสถานที่ที่ยังไม่รู้
- **C:** ใช้ทั้งสองแบบในคนละเหตุการณ์ ไม่บังคับให้ทุกงานจบด้วยการเลือกระหว่างช่วยคนกับหลักฐาน

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

## Q976

**คำถาม:** บริษัทคู่สัญญาควรเป็นจุดเชื่อมสำคัญด้านใด?

- **A:** เครื่องมือเฉพาะ ผู้เชี่ยวชาญ และการบำรุงรักษาที่โครงการขาดไม่ได้
- **B:** เงินทุนและการปกปิดบัญชีเป็นหลัก
- **C:** ควบคุมข้อมูลทักษะทั้งหมด รัฐต้องผ่านบริษัททุกครั้งที่ใช้งาน

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

## Q977

**คำถาม:** ถ้าทีมทำให้บริษัทหยุดสนับสนุน ฝ่ายรัฐควรตอบสนองอย่างไร?

- **B:** รัฐยึดทรัพยากรและบังคับผู้เชี่ยวชาญให้ทำงานต่อ
- **C:** เริ่มจาก A แล้วอาจยกระดับเป็น B ตามสถานการณ์

## Q979

**คำถาม:** การตัดแรงคุ้มครองทางอำนาจควรเกิดจากอะไร?

- **A:** ส่งหลักฐานให้ฝ่ายตรวจสอบหรือผู้มีอำนาจอีกกลุ่มที่มีเหตุผลจะลงมือ
- **B:** ทำให้ผู้คุ้มครองต้องถอนตัวเพื่อรักษาตัวเอง โดยยังไม่รับประกันว่าเขาจะถูกลงโทษ
- **C:** มีทั้ง A+B ตามหลักฐานและสถานการณ์ โดยทีมยังต้องทำภารกิจภาคสนามต่อเอง

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

## Q980

- **C:** มีทั้ง A+B การเสียทรัพยากรจึงทำให้ความขัดแย้งภายในรุนแรงขึ้นด้วย

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

- **C:** บางครั้งเสนอร่วมมือชั่วคราวกับทีม แต่ทีมเสี่ยงถูกใช้เป็นเครื่องมือ
