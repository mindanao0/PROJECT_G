# ฐานหลักและสถานย่อย — ส่วน 2

[ดัชนีหมวด](../../02_OPEN_QUESTIONS.md) · [วิธีบันทึก](../README.md)

รับคำตอบ2026-10-22. ข้อที่ไม่ได้ระบุใช้คำแนะนำตามคำสั่งเจ้าของ. เป็นหลักการของเครือข่ายก่อนประวัติและคดีเต็ม ไม่สร้างเหตุการณ์เฉพาะหรือผังสถานที่ยืนยันเอง. Q973/Q975มีคำแก้ไขตรงจากเจ้าของ ใช้เหนือคำแนะนำเดิม.

## Q971

**คำถาม:** สถานทดลองย่อยแต่ละแห่งควรต่างกันอย่างไร?

- **A:** แต่ละแห่งมีหน้าที่หลักเฉพาะ เช่น ประเมินต้นแบบ เตรียมผู้รับ หรือดูแลหลังทดลอง
- **B:** ทำงานคล้ายกัน แต่ต่างระดับความสำคัญและการรักษาความปลอดภัย
- **C:** แต่ละแห่งทดลองแนวทางของตัวเอง แข่งกันส่งผลงานให้ฐานหลัก

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ อ่านร่วมQ973ล่าสุด: งานเฉพาะของสถานย่อยช่วยเพิ่มวัตถุดิบ/กำลังรองรับ ไม่ใช่ความสามารถเฉพาะที่ฐานหลักทำเองไม่ได้

## Q972

**คำถาม:** เมื่อทีมจัดการสถานทดลองย่อยสำเร็จ ควรได้อะไรที่มีผลต่อเรื่อง?

- **A:** ช่วยคนและได้ข้อมูลเกี่ยวกับโครงการ
- **B:** ลดกำลังหรือความสามารถที่ฝ่ายร้ายจะใช้ในภารกิจหลัง
- **C:** มีทั้ง A+B แต่ขึ้นกับสิ่งที่ทีมเลือกทำและรักษาไว้ได้

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** C — รับคำแนะนำตามคำสั่ง “ที่เหลือเอาตามเเนะนำ”

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

รับคำแนะนำ ผลต่อผู้เสียหาย/กำลัง/หลักฐานมีจริง แต่ไม่ปิดความสามารถฐานหลักอัตโนมัติเมื่อฐานย่อยหยุด

## Q973

**คำถาม:** ฐานหลักควรพึ่งสถานย่อยมากแค่ไหน?

- **A:** รับผลทดลอง คน และทรัพยากรจากสถานย่อย แต่ยังดำเนินงานบางส่วนได้เอง
- **B:** หากสถานย่อยสำคัญหยุด ฐานหลักเดินโครงการต่อไม่ได้
- **C:** สถานย่อยเป็นเพียงฉากบังหน้า งานสำคัญทั้งหมดอยู่ฐานหลัก

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** CUSTOM — ฐานหลักทำได้ทุกอย่าง ฐานย่อยเพิ่มวัตถุดิบ — เจ้าของระบุโดยตรง

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

คำตอบตรงเจ้าของ: “ฐานหลักทำได้ทุกอย่าง เเค่ฐานย่อยเหมือนตัวเพิ่มวัตถุดิบเฉยๆ”. ฐานหลักทำกระบวนการโครงการครบเองได้ สถานย่อยช่วยเพิ่มวัตถุดิบ/กำลังรองรับ ไม่ใช่ขั้นตอนจำเป็นที่ขาดแล้วฐานหลักทำต่อไม่ได้. การเสียฐานย่อยอาจลดจำนวน/ความเร็วและโอกาสได้ต้นแบบ แต่ไม่ตัดความสามารถฐานหลักเอง. ไม่ตีความว่าฐานหลักสร้างคน/วัสดุจากศูนย์หรือไม่พึ่งทรัพยากรภายนอกเลย

## Q974

**คำถาม:** บทของฐานหลักควรเป็นอะไร?

- **A:** ศูนย์รวมงานวิจัยรุ่นล่าสุด ข้อมูลต้นฉบับ และการสั่งการโครงการ
- **B:** ที่เก็บผู้ทดลองรุ่นสำเร็จและเตรียมส่งออกปฏิบัติการเป็นหลัก
- **C:** ศูนย์บัญชาการที่แทบไม่มีการทดลองจริง ต้องตามหาสถานวิจัยอีกแห่ง

**แนะนำเดิม:** A

**คำตอบ 2026-10-22:** A+B — เจ้าของระบุโดยตรง

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

เจ้าของเลือกA+B รวมวิจัยรุ่นล่าสุด ข้อมูลต้นฉบับ การสั่งการ การเก็บผู้ทดลองรุ่นสำเร็จและเตรียมส่งออกปฏิบัติการ. ไม่ย้ายงานจริงทั้งหมดไปยังฐานลับอีกแห่งโดยนัย

## Q975

**คำถาม:** การเข้าถึงฐานหลักควรขึ้นกับอะไร?

- **A:** หลักฐานและข้อมูลที่ช่วยหาตำแหน่งกับเข้าใจวิธีทำงานของสถานที่
- **B:** ผลจากภารกิจก่อนหน้าที่ลดกำลังสนับสนุนและแรงคุ้มครอง
- **C:** ใช้ทั้ง A+B โดยมีหลายเส้นทาง ไม่ต้องทำทุกภารกิจให้ครบ

**แนะนำเดิม:** C

**คำตอบ 2026-10-22:** A — เจ้าของระบุโดยตรง

**สถานะ:** CONFIRMED ตามขอบเขตคำตอบ

เจ้าของเลือกA: การเข้าถึงอาศัยหลักฐาน/ข้อมูลหาตำแหน่งและเข้าใจสถานที่ ไม่บังคับตัดเครือข่าย/ฐานย่อยก่อนจึงเปิดทาง. ผลการตัดกำลังตามQ938/Q955/Q972ยังมีผลต่อสถานการณ์/ความยากได้ แต่ไม่เอามาเป็นเงื่อนไขเข้าถึงแบบBโดยอัตโนมัติ. รายละเอียดวิธีเข้า/ความปลอดภัยยังOPEN
