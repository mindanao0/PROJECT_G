### กติกาการยืนยัน

บันทึกคำตอบพร้อมวันที่ แหล่งคำสั่ง และข้อยกเว้นใน `02` → เปลี่ยน decision เป็น `CONFIRMED` เท่าที่มีหลักฐาน → ซิงก์เอกสารปลายทาง → ทวน validation ที่เกี่ยวข้อง ไม่มีคำตอบแปลว่ายัง `OPEN/PROPOSED` ไม่ใช่ยอมรับ

ถ้าตอบ “ตามคำแนะนำทั้งหมด” บันทึกว่าเลือกตัวเลือกแนะนำของคำถามที่ตัดสินใจได้ แต่ข้อมูลจริง Q17/Q18 ยังต้อง `UNKNOWN` จนมีข้อมูล ส่วน R12 ยังห้ามเริ่ม code หากไม่มีคำสั่งใหม่ที่อนุญาต
