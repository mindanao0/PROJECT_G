# PROJECT_G — แนวภาพ Ink Noir และการเล่าด้วยภาพนิ่ง

**สถานะ · เลือกใช้กับการทดลองภาพรอบ 2026-11-27**

เจ้าของเลือกพัฒนาจากตัวอย่าง B · Ink Noir และเสนอให้เล่าด้วยภาพนิ่งที่สลับตามจังหวะเรื่อง การทดลองนี้ต่อจาก [Q236–Q242](../questions/topics/21_visual_direction.md) ที่ให้เทียบหลายทิศทางก่อนกำหนดรูปลักษณ์ สถานะภาพแต่ละใบคือแบบทดลอง ส่วนข้อเท็จจริงของตัวละครและโลกอ้างอิงจากคำตอบเดิมในบรีฟรายหัวข้อ

## แนวภาพ

- ใช้กลุ่มเงาหมึกดำและพื้นที่สว่างกำกับสายตา ให้ผู้เล่นเห็นสีหน้า ท่าทาง และหลักฐานในจังหวะที่เรื่องต้องการ
- ใช้เงาหมึกดำเป็นแกนร่วมของโทนอุ่นและโทนเย็น เลือกโทนตามเวลา สภาพอากาศ และแหล่งแสง ตัวละครมีรูปหน้า รูปร่าง ทรงผม และท่าทางต่างกัน
- ให้เทคโนโลยีอนาคตอ่านได้จากรูปทรง วิธีทำงาน และวิธีที่คนใช้ เห็นความเก่าผ่านโครงสร้างเมืองและรอยซ่อมบนอุปกรณ์ ศูนย์กลางใช้วัสดุและการติดตั้งที่ดูแลได้ดีกว่า
- ให้แสงและพื้นผิวพาสายตาไปที่คน สิ่งที่กำลังทำ หรือหลักฐานสำคัญ
- ใช้พื้นผิวหมึกและรอยสึกบนพื้นที่ที่ช่วยเล่าเรื่อง เว้นพื้นที่รอบดวงตา มือ และวัตถุสำคัญให้ภาพอ่านง่าย

### แสงตามเวลาและอากาศ

เจ้าของรับทั้งโทนอุ่นและโทนเย็น ใช้เป็นเงื่อนไขของแต่ละภาพ ตัวอย่างการจัดแสงด้านล่างเป็นแนวทางทดสอบ

| สภาพฉาก | แนวทางแสง |
|---|---|
| เช้า | แสงฟ้ากระจาย ส่วนที่รับแดดมีขอบอุ่นบาง ๆ |
| เที่ยง | แสงกลางค่อนไปทางขาว เงาหมึกชัดใต้ที่บังแดด |
| เย็น | แสงอำพันต่ำบนผิวอาคารและขอบตัวละคร |
| กลางคืน | เงาหนักขึ้นตามแหล่งแสงในพื้นที่ อาจลองนีออนที่ย่านค้า |
| ฝน | ใช้ร่วมกับแต่ละช่วงเวลา แสงกระจายและสะท้อนบนพื้นผิวเปียก |

[การจัดแสงตามเวลาและสภาพอากาศใน Cyberpunk 2077 — GDC](https://www.gdcvault.com/play/1027959/Advanced-Graphics-Summit-Cyberpunk-2077)

### เทคโนโลยีที่เตรียมทดสอบภาพ

ภาพรางแขวนก่อนหน้ายังไม่ผ่านการเลือกแบบ ผลตอบรับให้ค้นคว้ารูปทรงของอุปกรณ์และวิธีใช้งานที่เปลี่ยนไปจากปัจจุบันก่อนทำภาพรอบต่อไป ดูการประเมินที่ [บรีฟตลาดจุดต่อรถ](../locations/transit-market.md#แบบทดสอบระบบขนส่งอนาคต)

| หัวข้อ | แนวคิดสำหรับ PROJECT_G | สิ่งที่ช็อตต้องทำให้เห็น |
|---|---|---|
| อุปกรณ์ส่วนตัวและสิทธิ์บริการ | แถบบางแนบผิวหรือโมดูลใต้ผิวทำหน้าที่เป็นอินเทอร์เฟซและยืนยันตัวตน รุ่นข้างนอกครอบผิวถอดเปลี่ยนได้ ทดลองให้สัญญาณใช้บริการแต่ละอย่างแยกกัน | เจ้าของใช้แถบที่ข้อมือจ่ายเงินได้แล้วเจอการตอบกลับอีกแบบที่ทางต่อรถ คนดูเห็นผลที่ต่างกันจากท่าทางและการตอบสนองของอุปกรณ์ |
| เครื่องมือคลินิก | พื้นผิวบนแท่นตรวจเปลี่ยนรูปเป็นตัวประคองตามขนาดแขนและขยับเข้าสู่ตำแหน่งตรวจ ตัวเครื่องประกอบจากส่วนที่เปลี่ยนได้ รุ่นชุมชนมีชิ้นส่วนและการประกอบต่างจากรุ่นของศูนย์กลาง | เห็นพื้นผิวสองสถานะ ท่าวางแขน และตำแหน่งชิ้นส่วนที่ช่างเปลี่ยนได้ |
| การเปลี่ยนเส้นทางในสถานี | ลองห้องโดยสารที่ถ่ายจากแนวเดินทางในเมืองเข้าแกนแนวตั้งของสถานีเพื่อไปเทียบจุดต่อรถท้องถิ่น | เห็นห้องโดยสารเดียวกันทั้งตอนเดินทางแนวราบและตอนเข้าแกนแนวตั้ง รวมถึงทางที่ผู้โดยสารไปต่อ |
| อุปกรณ์ถ่ายความสามารถ | ออกแบบชุดถ่ายความสามารถโดยเฉพาะ ให้เห็นความต่างของอุปกรณ์พกพาทั่วไปกับเครื่องเฉพาะที่รองรับข้อมูลใช้ครั้งเดียว | เห็นจุดที่ตลับเข้ากับเครื่องและการเปลี่ยนสภาพของตลับหลังใช้ สภาพตลับจริงเป็นแบบทดลอง |

รุ่นอุปกรณ์ ตำแหน่งบนร่างกาย กลไก และผังยังเป็นข้อเสนอ อ้างคำตอบเรื่องสิทธิ์และข้อจำกัด [Q531](../questions/topics/13_implants_and_device_market.md#q531), [Q534](../questions/topics/13_implants_and_device_market.md#q534), [Q553](../questions/topics/13_implants_and_device_market.md#q553), [Q555](../questions/topics/13_implants_and_device_market.md#q555), [Q593](../questions/topics/13_implants_and_device_market.md#q593) และ [กฎการถ่ายความสามารถ](../story/01_experimental_humans_factions.md)

- Territory Studio ใช้ปฏิสัมพันธ์สามมิติช่วยให้เทคโนโลยีใน Ghost in the Shell รองรับการแสดงและการเล่าเรื่อง ทดลองนำหลักที่ว่าอุปกรณ์เปลี่ยนท่าทางของคนมาใช้กับช็อตภาพนิ่ง [ผลงานของ Territory Studio](https://territorystudio.com/project/ghost-in-the-shell/)
- CD PROJEKT RED ให้อุปกรณ์และการแต่งกายสะท้อนฐานะใน Night City นำหลักนี้มาทดสอบสองรุ่นของอุปกรณ์ที่ทำหน้าที่เดียวกัน ให้เห็นรอยซ่อม อะไหล่ และคุณภาพที่ต่างกัน [คู่มือภาพของ CD PROJEKT RED](https://www.cyberpunk.net/en/news/28441/c-usb-01-backup-concept-art-cp-visual-styles)
- DuoSkin ทดลองรับสัมผัส แสดงผล และสื่อสารจากอุปกรณ์แนบผิว ส่วน inFORM แสดงข้อมูลผ่านพื้นผิวที่เปลี่ยนรูปได้ ใช้เป็นจุดตั้งต้นสำหรับรูปแบบการใช้งานในโลกสมมติ [DuoSkin](https://www.media.mit.edu/projects/2ndskin/overview/) · [inFORM](https://tangible.media.mit.edu/project/inform/)
- MULTI ใช้มอเตอร์เชิงเส้นให้ห้องลิฟต์เคลื่อนในแนวตั้งและแนวนอน เป็นจุดตั้งต้นของแนวคิดเชื่อมรถกับสถานีในพื้นที่หลายระดับ [TK Elevator](https://www.tkelevator.com/global-en/products/innovations/multi/)
- Remember Me นำเทคโนโลยีความจำมาผูกกับตลาดและผู้ควบคุมข้อมูล ใช้หลักเดียวกันตั้งคำถามว่าใครเข้าถึงอุปกรณ์ถ่ายความสามารถและผลของการเข้าถึงนั้นสะท้อนในฉากอย่างไร [คำอธิบายจากผู้กำกับเกม](https://blog.playstation.com/archive/2013/05/17/remember-me-new-art-interactive-journal-director-qa/)

## ภาพนิ่งตัดตามช็อต

แต่ละภาพแทนหนึ่งการจัดเฟรมในฉาก ภาพเดิมอยู่ได้หลายบรรทัด สลับเมื่อมีข้อมูลใหม่ ความรู้สึกเปลี่ยน จุดสนใจย้าย หรือผลของทางเลือกปรากฏ การทดลองใช้ภาพนิ่งกับข้อความและเสียงบรรยากาศเป็นหลัก

| จังหวะ | ภาพทดลองในฉาก Maya กับ Elias |
|---|---|
| เปิดพื้นที่และความสัมพันธ์ | ภาพคู่ที่โต๊ะ Maya อธิบาย Elias ฟังและไล่ดูข้อมูล |
| พบข้อมูล | ภาพใกล้มือที่ชี้เวลาในบันทึกสองใบที่ไม่ตรงกัน |
| เห็นการตอบสนอง | ภาพใกล้ Elias ชะงักก่อนพูด เสียงรถไฟผ่านนอกหน้าต่าง |
| ผู้เล่นลงมือ | คงภาพที่อ่านง่ายแล้วแสดงตัวเลือกถามที่มาของบันทึกหรือเก็บข้อสังเกตไว้ |

ตัวอย่างนี้ใช้ทดสอบจังหวะและการอ่านภาพ รายละเอียดคดีและข้อความบทยังเป็นตัวอย่าง ภาพหลักสามารถใช้ร่วมกันหลายทางเลือก เพิ่มช็อตใหม่เมื่อผลลัพธ์ที่ผู้เล่นมองเห็นต่างกัน หลักฐานที่จำเป็นต่อการตัดสินใจมีข้อความให้อ่านได้ด้วย

## หลักสำหรับประเมินงานผลิต

- นับภาพเปิดฉาก ภาพเดี่ยว ภาพใกล้วัตถุ ภาพตอบสนอง และภาพผลลัพธ์ที่แตกต่างกันจริง ใช้จำนวนช็อตใหม่ เวลาแก้ภาพ และจำนวนจุดเปลี่ยนภาพในทางเลือกเพื่อประเมินงานหลังทดลองฉากสั้น
- ตรวจว่ารูปร่างและสีหน้าแยกได้เมื่อแสดงขนาดหน้าจอเกม หลักฐานเห็นทันก่อนตัดสินใจ และยังมองออกว่าสถานที่สว่างกับสถานที่มืดอยู่ในเมืองเดียวกัน
- ให้ภาพเผยข้อมูลที่ผู้เล่นรู้ได้ในจังหวะนั้น เช่น มุมที่ปิดใบหน้า Iris ช่วงต้นและการไม่เห็นฐานลับจากทางเข้าศูนย์หลัก
- รายการภาพเดิมใน [แผนการผลิต](../05_PRODUCTION_AND_TECH.md#2-inventory-สำหรับ-s0) เป็นฐานเทียบของ slice เดิม จำนวนช็อตจริงรอนับจากลำดับเรื่องที่เลือกและการทดสอบแบบภาพนิ่ง
