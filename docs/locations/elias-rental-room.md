# ห้องเช่าของ Elias — บรีฟภาพทดลอง

**PROJECT_G · Ink Noir · 2026-11-27**

## ข้อมูลจากคำตอบ

Elias อยู่คนเดียวในห้องเช่าขนาดเล็กของอาคารเก่าหลายชั้น พื้นที่นั่งทำงานใช้พัก กินข้าวและอ่านข้อมูล แยกจากห้องนอน

[คำตอบที่พัก Q297–Q355](../questions/topics/15_housing_building_room.md#q297) · [การใช้พื้นที่และของจากการทดลอง](../questions/topics/15_housing_building_room.md#q411)

## ภาพที่ทดลอง

ภาพกว้างจากมุมโต๊ะกินข้าว เห็นคอมทั่วไป หน้าต่างใกล้อาคารข้างเคียง และประตูที่บ่งว่ามีห้องนอนแยก หลอดไฟหนึ่งดวงกับแสงจากนอกอาคารทำให้พื้นที่ดูคับแต่ยังอยู่ได้

## รายละเอียดที่ยังเปิด

ผังจริง ตำแหน่งอาคาร และชนิดหรือวิธีเก็บบันทึกหรือสิ่งของจากการทดลองเก่ายังเปิด ภาพไม่ระบุสิ่งของหรือจุดซ่อน
