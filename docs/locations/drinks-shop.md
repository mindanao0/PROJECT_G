# ร้านเครื่องดื่มชั้นล่าง — บรีฟภาพทดลอง

**PROJECT_G · Ink Noir · 2026-11-27**

## ข้อมูลจากคำตอบ

ร้านเครื่องดื่มตั้งอยู่ชั้นล่างของอาคารเก่าใกล้ทางเดิน มีมาก่อนวิกฤตและปรับตัวอยู่ต่อ มีเคาน์เตอร์ ที่นั่งทั่วไป มุมห่างและพื้นที่บริการหลังร้าน ช่วงคนบางตานั่งคุยได้โดยยังมองเห็นจากพื้นที่ร่วม

[คำตอบร้านและตำแหน่ง](../questions/topics/17_meeting_places_drink_shop.md#q387) · [รายละเอียดช่วงคนบางตาและพื้นที่](../questions/topics/17_meeting_places_drink_shop.md#q391)

## ภาพที่ทดลอง

มุมกว้างจากฝั่งถนน เห็นทั้งเคาน์เตอร์และมุมโต๊ะที่ขยับห่างออกไป ทดลองใช้แสงหน้าต่างกับโคมอุ่นเป็นจุดนำสายตา

## รายละเอียดที่ยังเปิด

ชื่อร้าน ผังจริง เวลา จำนวนโต๊ะ และรูปทรงของเครื่องดื่มหรืออุปกรณ์ยังเป็นพื้นที่ออกแบบ
