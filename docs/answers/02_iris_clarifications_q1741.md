# คำตอบชี้แจง Iris Q1741–Q1743

2026-11-19 ผู้ใช้ตอบ: “Q1741 = ข้อ Q1736 เลือกผิด น่าจะเลือก A ที่เหลือตามแนะนำ”

- Q1741: ผู้ใช้แก้ Q1736 จาก C เป็น A; เลือกเส้นรัก Iris หรือไม่เป็นสิทธิ์ผู้เล่น และความสัมพันธ์ค่อยพัฒนาเมื่อเลือก. รักษากรอบสี่เส้นรักและสิทธิ์ปฏิเสธเดิม.
- Q1742=A: หลังลาออก Iris ช่วงแรกคิดว่าความรู้เดิมไม่มีประโยชน์ แต่ค่อยพบว่ายังใช้ช่วยทีมได้; อ่านร่วม Q1733=A+C ไม่กำหนดเหตุการณ์หรือจังหวะละเอียด.
- Q1743=A: ความสนิทแบบเพื่อนไม่เปลี่ยนท่าทีมาก แต่เมื่อพัฒนาเส้นรักเธอค่อยเปิดเผยความรู้สึก; ตัวเลข/เกณฑ์คะแนนและการแสดงคะแนนยังไม่กำหนด ห้ามอนุมานว่าแสดงต่อผู้เล่น.

Q1561 และ Q839–Q862 ยังคงพัก.
