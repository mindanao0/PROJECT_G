# คำตอบอาชีพ Iris Q1767

2026-11-19 ผู้ใช้ตอบ “น่าจะเป็น A+C+E”.

รับเป็น **แนวทางที่ผู้ใช้เอนเอียง**: แฮกเกอร์สอดแนม/ตัวตนดิจิทัล (A), วิเคราะห์ซอฟต์แวร์/การสื่อสารของอุปกรณ์เชื่อมร่างกาย (C), และติดตามร่องรอยข่าวกรองดิจิทัล (E). ยังต้องกำหนดว่าหน้าที่ใดเป็นหลัก ขอบเขตความสามารถ ข้อจำกัด สถานะอาชีพ และเหตุพบ/เข้าทีม; ตัวอย่างในแต่ละตัวเลือกไม่ยืนยันอัตโนมัติ. งานเดิมไม่เกี่ยวกับโครงการลับและไม่รู้โครงการล่วงหน้า; ทักษะมาจากที่ใดยังไม่เลือก ไม่เพิ่มว่ารับทักษะจากโครงการ (ทีมหลักไม่รับ Q1068=C).

**ความซ้ำ:** ทีมเดิมมีผู้เชี่ยวชาญดิจิทัล Q1048–Q1049 และช่าง Q1050–Q1051; ยังไม่เลือกให้ Iris แทนหรือให้เป็นสองคน. ช่างเดิมตรวจซ่อมและปรับอุปกรณ์ แต่การแบ่งฮาร์ดแวร์/ซอฟต์แวร์เป็นข้อเสนอรอตัดสิน. Q997/Q1012/Q1026/Q1027 งานรัฐ/เหตุพยาน/ลาออกเดิมต้องตรวจผลกระทบหลังเลือกอาชีพและการเข้าทีม ยังไม่ยกเลิกหรือเปลี่ยนเนื้อหาเอง. คำตอบ Q1748=A+B และข้อเรียน/งานที่อิงอาชีพรัฐรอทวน ไม่อนุมานว่าใช้ได้ในอาชีพใหม่. Q1561 และ Q839–Q862 ยังคงพัก.
