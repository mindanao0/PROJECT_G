# คำตอบผู้คุ้มกัน — ลำดับชีวิต

Q1567=A — ตามคำแนะนำ: เริ่มงานบริษัทราวอายุ 18–20 ปี หลังการศึกษาทั่วไปและฝึก; ยังไม่ระบุปีเกิด อายุแน่นอน ระดับที่จบ หรือระยะเวลาการฝึกและงาน. Q839–Q862 และ Q1561 ยังคงพัก.
