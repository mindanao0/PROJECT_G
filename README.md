## สิ่งที่แผนใหม่นี้เสนอ

- ออกแบบจากความจริงที่เกิดขึ้นจริง → ใครรู้อะไร → หลักฐาน → ทางเลือก → ผลลัพธ์ ก่อนขยายบท
- ทดลองหนึ่งเหตุการณ์ **25–40 นาทีเป็นเป้าหมายที่ต้องวัด** แทนการทำบท 1–3 ทั้งชุดตั้งแต่แรก
- แบบทดลอง `S0` มี 12 scene nodes, 4 จุดเลือก และ 22 trace ที่เป็นไปได้ตามกติกาที่เสนอ
- คงความต้องการเรื่องความสัมพันธ์ ทีม สถานะ และ Level; เริ่มจากระบบเล็กที่มีผลจริง
- ประเมินเกม 12 บทใหม่หลังพิสูจน์งานเขียน การทดสอบ และกำลังผลิต ไม่ถือ 12 ชั่วโมงเป็นสัญญา

`S0` เป็น **ข้อเสนอสำหรับทดสอบแผน ไม่ใช่ canon** ชื่อบุคคล เพศ คู่รัก ผู้กระทำผิด และตอนจบสุดท้ายยังไม่ยืนยัน ไม่มี requirement ให้ใช้ AI ระหว่างเล่น และยังไม่ได้เลือก engine หรือแพลตฟอร์ม

## ตอบคำถามอย่างไร

ตอบเฉพาะรหัส เช่น `Q01=A, Q02=A, Q03=B` พร้อมข้อแก้ไข หรือเลือกใช้คำแนะนำทั้งชุดแล้วระบุข้อยกเว้นได้ จำนวนคน เวลาว่าง งบประมาณ และอุปกรณ์ต้องใช้ข้อมูลจริง; หากยังไม่รู้ให้บันทึกว่า `UNKNOWN` ห้ามโมเดลเดาแทน

คำถามทั้งหมดอยู่ [ที่เดียว](docs/02_OPEN_QUESTIONS.md) มีทางทำงานต่อระหว่างรอคำตอบ ไม่ต้องถามซ้ำสิ่งที่ยืนยันแล้วใน brief
